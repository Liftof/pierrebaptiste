Audience privacy / Confidentialité de la mesure

This site counts views on selected public pages, not individual visitors. The script sends only a site key and a predefined page category to a private counter. The script does not send your submissions, exact URL, cookies or browsing identifiers. Vercel receives the IP address to handle the counter request; the audience counter does not store it in its statistics, which contain only daily totals for this site. If you opt out, only that choice is saved in this browser.

Ce site compte les vues de certaines pages publiques, pas les visiteurs individuels. Le script transmet seulement le nom du site et une catégorie de page prédéfinie à un compteur privé. Le script ne transmet ni vos saisies, ni l’URL exacte, ni cookie, ni identifiant de navigation. Vercel reçoit l’adresse IP pour traiter la requête du compteur ; celui-ci ne la conserve pas dans ses statistiques, limitées à des totaux quotidiens pour ce site.
